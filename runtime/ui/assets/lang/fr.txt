# L'assistant du premier lancement
Welcome = Bienvenue
This app plays the game from your own disc. Nothing of the game comes with it: it is built on this computer, from your disc image, once. = Cette app lance le jeu depuis ton propre disque. Rien du jeu n'est fourni avec : il est construit sur cet ordinateur, depuis ton image disque, une seule fois.
The next few steps choose the disc, prepare the game, and set up the controller, the display and texture packs. All of it can be changed later in Settings. = Les étapes suivantes choisissent le disque, préparent le jeu, et règlent la manette, l'affichage et les packs de textures. Tout se change ensuite dans les réglages.
Your disc = Ton disque
Choose your disc image (.iso or .ciso), or drop it on this window. = Choisis ton image disque (.iso ou .ciso), ou dépose-la sur cette fenêtre.
Preparing the game = Préparation du jeu
The game is built from your disc, on this computer, with nothing to install. It takes a minute or two, and is done once. = Le jeu est construit depuis ton disque, sur cet ordinateur, sans rien à installer. Ça prend une minute ou deux, une seule fois.
Press buttons and move the sticks to try them. = Appuie sur des boutons et bouge les sticks pour les essayer.
Every button can be changed in Settings, Controls. = Chaque bouton se change dans Réglages, Contrôles.
Display = Affichage
Packs made for Dolphin work as they are: copy a pack's GLME01 folder into the textures folder. = Les packs faits pour Dolphin marchent tels quels : copie le dossier GLME01 d'un pack dans le dossier des textures.
Use texture packs = Utiliser les packs de textures
All set = C'est prêt
Esc (or Back on a controller) pauses the game: saves, settings, back to the launcher. = Échap (ou Back sur une manette) met le jeu en pause : sauvegardes, réglages, retour au lanceur.
Go to the launcher = Aller au lanceur
Next = Suivant
1 texture = 1 texture
